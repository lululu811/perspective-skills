# 分级蒸馏模式 v3.0

> 根据人物知名度和信息充足度，选择合适的蒸馏模式

## 三种模式对比

| 维度 | 完整模式 | 核心模式 | 最小模式 |
|------|---------|---------|---------|
| **适用对象** | 知名公众人物 | 学者/作家/专业人士 | 小众人物/非公众人物 |
| **Agent数量** | 6个全部 | 3个核心Agent | 1-2个核心Agent |
| **预期来源数** | ≥50条 | ≥20条 | ≥10条 |
| **心智模型数量** | 3-7个 | 2-4个 | 1-3个 |
| **时间投入** | 2-4小时 | 1-2小时 | 30-60分钟 |
| **质量预期** | 高（置信度🟢为主） | 中（🟢🟡混合） | 低（🟡🔴为主） |
| **诚实边界** | 标准篇幅 | 加大篇幅 | 大幅加大 |

---

## 模式1：完整模式（Full Mode）

### 适用条件
- ✅ 知名公众人物（如巴菲特、芒格、塔勒布、达利欧）
- ✅ 有丰富的公开著作、访谈、决策记录
- ✅ 网络搜索结果≥50条高质量来源
- ✅ 用户追求高质量Skill

### 执行流程
按v2.0标准流程执行：
1. Phase 0: 入口确认
2. Phase 0.5: 创建Skill目录
3. Phase 1: 6个Agent全部启动
4. Phase 1.5: 质量门禁（必须达到A/B级）
5. Phase 2: 框架提炼（提取3-7个心智模型）
6. Phase 2.5: 提炼确认
7. Phase 3: Skill构建
8. Phase 4: 质量验证
9. Phase 5: 双Agent精炼

### Agent配置
全部6个Agent：
- Agent 1: 著作与系统思考
- Agent 2: 对话与访谈 ⭐
- Agent 3: 表达DNA
- Agent 4: 他者视角
- Agent 5: 决策记录 ⭐
- Agent 6: 人物时间线

### 质量要求
- 一手来源占比 ≥ 60%
- 总来源数 ≥ 50条
- Agent 2（对话）和Agent 5（决策）必须达到"高"过程密度
- 质量门禁评级必须达到A或B

### 输出示例
```markdown
# 心智模型：7个
1. 三齿轮模型（🟢高/✅持续）
2. 分子×分母×g因子（🟢高/✅持续）
3. 吃鸡缩圈（🟢高/🔄演化）
...

# 决策启发式：10条
# 表达DNA：完整分析
# 内在张力：3对
# 诚实边界：标准篇幅（~200字）
```

## 模式2：核心模式（Core Mode）

### 适用条件
- ⚠️ 学者/作家/专业人士（如某领域教授、畅销书作者）
- ⚠️ 有著作但访谈/决策记录较少
- ⚠️ 网络搜索结果20-50条
- ⚠️ 用户时间紧张，追求快速可用

### 执行流程
简化流程：
1. Phase 0: 入口确认
2. Phase 0.5: 创建Skill目录
3. Phase 1: **只启动3个核心Agent**
   - Agent 1: 著作与系统思考 ⭐
   - Agent 2: 对话与访谈 ⭐（如有）
   - Agent 5: 决策记录 ⭐（如有）
   - **跳过** Agent 3（表达DNA）、Agent 4（他者视角）、Agent 6（时间线）
4. Phase 1.5: 质量门禁（达到C级以上即可）
5. Phase 2: 框架提炼（提取2-4个心智模型）
6. Phase 3: Skill构建（简化版SKILL.md）
7. **跳过** Phase 2.5、Phase 4、Phase 5

### Agent配置
只启动3个核心Agent：
```python
core_agents = [
    "01-writings",      # 必须有
    "02-conversations", # 优先
    "05-decisions"      # 优先
]
```

**为什么选这3个**：
- 著作：系统性思考，最可靠
- 对话：即兴思维过程，揭示真实推理
- 决策：实际行动，言行一致性检验

**为什么跳过其他3个**：
- 表达DNA：可以从著作和对话中推断
- 他者视角：可以从批评中推断，非必需
- 时间线：可以从著作出版时间推断

### 质量要求
- 一手来源占比 ≥ 50%
- 总来源数 ≥ 20条
- Agent 1必须有，Agent 2和5至少有一个
- 质量门禁评级达到C级即可

### 输出示例
```markdown
# 心智模型：3个
1. [模型1]（🟢高/✅持续）
2. [模型2]（🟡中/✅持续）
3. [模型3]（🟡中/🔄演化）

# 决策启发式：5条
# 表达DNA：简化分析（从著作推断）
# 内在张力：1-2对
# 诚实边界：加大篇幅（~400字）
#   - 明确标注"基于有限素材"
#   - 列出信息不足的维度
```

### 快速启动命令
```bash
# 使用核心模式
python3 scripts/nuwa-distill.py --mode core [人名]
```

## 模式3：最小模式（Minimal Mode）

### 适用条件
- ❌ 小众人物/非公众人物
- ❌ 信息严重匮乏（<20条来源）
- ❌ 用户只有少量本地素材
- ❌ 蒸馏自己/朋友/同事

### 执行流程
极简流程：
1. Phase 0: 入口确认（**必须用户提供本地素材**）
2. Phase 0.5: 创建Skill目录
3. Phase 1: **纯本地语料模式**
   - **不启动网络搜索Agent**
   - 只分析用户提供的素材
   - 按1-2个维度分类（著作 or 决策）
4. **跳过** Phase 1.5（无质量门禁）
5. Phase 2: 框架提炼（提取1-3个心智模型）
6. Phase 3: Skill构建（极简版SKILL.md）
7. **跳过** Phase 2.5、Phase 4、Phase 5

### Agent配置
不启动标准Agent，改为**素材分析**：
```python
# 纯本地语料分析
local_analysis = {
    "type": "local-only",
    "sources": "用户提供的素材",
    "dimensions": 1-2,  # 只分析素材覆盖的维度
    "expectations": "降低"
}
```

### 素材收集清单
提供给用户：
```markdown
## 请提供以下素材（至少一项）

### 必须提供（至少1项）
- [ ] 写过的文章/笔记（≥5篇）
- [ ] 做过的重大决策（≥3个，含背景和结果）
- [ ] 核心信念清单（≥5条）

### 强烈建议提供
- [ ] 明确反对的做法（≥3条）
- [ ] 表达样本（微信聊天记录、邮件、演讲）
- [ ] 他人评价（同事/朋友的观察）

### 可选提供
- [ ] 推荐书单（揭示智识谱系）
- [ ] 职业转折点（为何做某个选择）
- [ ] 事后反思（承认错误的案例）
```

### 质量要求
- **无硬性质量门禁**
- 一手来源占比 = 100%（全部来自用户提供）
- 总来源数 ≥ 10条（用户提供的素材）
- 心智模型数量：1-3个（宁少勿多）

### 输出示例
```markdown
# 心智模型：2个
1. [模型1]（🟡中/✅持续）
   - 来源：用户提供的文章A、决策B
2. [模型2]（🔴推测/✅持续）
   - 来源：用户自述，未经验证

# 决策启发式：3条
# 表达DNA：极简分析（基于有限样本）
# 内在张力：可能无（信息不足）
# 诚实边界：大幅加大（~600字）
#   - 明确标注"基于用户提供有限素材"
#   - "可能不完整，建议补充更多素材"
#   - "无法验证的部分已标注🔴推测"
#   - "此Skill仅供参考，不宜作为决策依据"
```

### 特别提示
```markdown
⚠️  最小模式的Skill质量有限：
- 心智模型可能不准确
- 表达DNA可能不全面
- 决策启发式可能不适用
- 仅适合个人参考，不适合对外分享

建议：
1. 后续补充更多素材，升级为"核心模式"
2. 使用时明确告知用户"这是基于有限素材的初步提炼"
```

## 模式选择决策树

```
开始蒸馏
  ↓
蒸馏对象是知名公众人物？
  ├─ 是 → 网络搜索结果≥50条？
  │       ├─ 是 → ✅ 完整模式
  │       └─ 否 → 用户时间充足？
  │               ├─ 是 → ⚠️ 核心模式（但期望降低）
  │               └─ 否 → ⚠️ 核心模式
  │
  └─ 否 → 有丰富本地素材？（≥20条）
          ├─ 是 → 学者/作家/专业人士？
          │       ├─ 是 → ✅ 核心模式
          │       └─ 否 → ⚠️ 最小模式（但素材充足）
          │
          └─ 否 → ❌ 最小模式
                  提示：信息严重不足，建议补充素材或更换对象
```

## 自动推荐逻辑

在Phase 0.5创建Skill目录时，自动评估并推荐模式：

```python
def recommend_mode(person_name: str, local_sources: List[Path]) -> str:
    """根据人物知名度和素材充足度推荐模式"""

    # 检查是否为知名公众人物
    known_figures = [
        "巴菲特", "芒格", "塔勒布", "达利欧", "贝索斯", "马斯克",
        "Naval", "Paul Graham", "Ben Horowitz", "Ray Dalio"
    ]

    is_known = any(name in person_name for name in known_figures)

    # 检查本地素材数量
    local_count = len(local_sources)

    # 决策逻辑
    if is_known:
        return "full"  # 知名人物默认完整模式
    elif local_count >= 20:
        if local_count >= 50:
            return "full"  # 素材非常充足
        else:
            return "core"  # 素材较充足
    else:
        return "minimal"  # 素材不足
```

## 模式切换

### 降级（从完整→核心→最小）
**触发条件**：
- Phase 1.5质量门禁不通过（评级D或F）
- 用户时间紧张
- 发现信息严重不足

**操作**：
1. 保留已完成的Agent输出
2. 跳过剩余Agent
3. 用已有素材继续Phase 2
4. 加大诚实边界篇幅

### 升级（从最小→核心→完整）
**触发条件**：
- 用户补充了更多素材
- 发现更多信息来源
- 对Skill质量有更高要求

**操作**：
1. 将新素材添加到`sources/`
2. 启动缺失的Agent
3. 重跑Phase 1.5质量门禁
4. 用更充足的素材重跑Phase 2

人物：查理·芒格

推荐模式：✅ 完整模式

推荐模式：✅ 核心模式

网络搜索：不适用

推荐模式：✅ 最小模式
理由：非公众人物，纯本地语料

公开素材：少量（几篇访谈，少量决策记录）

理由：信息不足，但有少量素材可用

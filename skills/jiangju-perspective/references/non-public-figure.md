# 非公众人物策略 v3.0

> 蒸馏自己、朋友、同事或小众人物的特殊处理

## 适用场景

- 用户说"蒸馏我自己"
- 蒸馏对象不是公众人物
- 网络搜索结果<20条
- 只有用户提供的本地素材

---

## 核心原则

### 1. 纯本地语料模式

- 不启动网络搜索Agent
- 完全依赖用户提供的素材
- 降低期望，接受不完美

### 2. 素材收集清单

提供给用户的具体清单：

#### 必须提供（至少1项）
- 写过的文章/笔记（5篇以上）
  - 博客、公众号文章、内部备忘录、日记等
  - 能体现系统性思考的长文
- 做过的重大决策（3个以上）
  - 决策背景、考虑因素、最终选择、结果
  - 事后反思（如果有）
- 核心信念清单（5条以上）
  - "我相信..."、"我认为..."、"我坚持..."
  - 反复强调的价值观

#### 强烈建议提供
- 明确反对的做法（3条以上）
  - "我绝对不..."、"我最讨厌..."、"我反对..."
  - 反模式比正模式更能揭示人格
- 表达样本
  - 微信聊天记录（脱敏后）
  - 邮件（脱敏后）
  - 演讲/分享的录音/文字稿
- 他人评价
  - 同事/朋友/家人对你的观察

#### 可选提供
- 推荐书单（最喜欢的书3本以上）
- 职业转折点（为何做某个选择）
- 事后反思（承认错误的案例）

### 3. 降低期望

#### 预期调整
- 心智模型：1-3个（而非3-7个）
- 决策启发式：2-5条（而非5-10条）
- 表达DNA：简化分析（基于有限样本）
- 内在张力：可能无（信息不足）
- 诚实边界：大幅加大篇幅（600字左右）

#### 使用限制
- 不适合对外分享
- 不宜作为决策依据
- 仅适合个人参考
- 可以用于自我反思

#### 明确标注
在SKILL.md开头添加警告：

> 本Skill基于用户提供的有限素材提炼，可能不完整。
> 建议后续补充更多素材，升级为"核心模式"或"完整模式"。

## 执行流程

### Phase 0: 入口确认（特殊处理）

#### 特殊问题
1. 蒸馏对象: 用户本人/朋友/同事
2. 素材来源: 纯本地（无网络搜索）
3. 期望管理: 
   - "由于信息有限，我们只能提炼1-3个心智模型"
   - "可能不如公众人物的Skill全面"
   - "但作为自我反思工具，已经足够有价值"
4. 用途: 自我反思/理解他人（非对外分享）

### Phase 0.5: 创建Skill目录

```
[skill目录]/
├── sources/
│   ├── books/          # 用户提供的书籍/文章
│   ├── transcripts/    # 用户提供的访谈/对话
│   └── articles/       # 用户提供的文章
└── references/
    └── research/       # 分析结果
```

### Phase 1: 纯本地语料分析

#### 不启动标准Agent
改为用户直接分析素材

#### 分析方法
1. 阅读所有素材
   - 标记反复出现的观点
   - 标记强烈的情感（热爱/反对）
   - 标记决策逻辑

2. 分类到维度
   - 系统性思考 → 01-writings.md
   - 对话/问答 → 02-conversations.md（如有）
   - 碎片表达 → 03-expression-dna.md（如有）
   - 决策记录 → 05-decisions.md（如有）

3. 提取模式
   - 反复出现的观点 = 候选心智模型
   - 强烈反对的 = 反模式
   - 决策逻辑 = 决策启发式

### Phase 2: 简化提炼

#### 心智模型（1-3个）
- 只提取出现3次以上的观点
- 不要求跨域复现（素材太少）
- 标注置信度为🟡中（基于有限素材）

#### 决策启发式（2-5条）
- 从用户提供的决策案例中提取
- 格式："如果X，则Y"

#### 表达DNA（简化）
- 基于用户提供的表达样本
- 样本量太少时标注"基于有限样本"

### Phase 3: 构建极简SKILL.md

#### 简化结构
```markdown
# [人名] 视角

> ⚠️ 本Skill基于有限素材提炼，仅供参考

## 核心心智模型（1-3个）
1. [模型1]（🟡中/✅持续）
   - 来源：[用户提供的素材]

## 决策启发式（2-5条）
1. 如果X，则Y

## 反模式
- [明确反对的做法]

## 诚实边界（加大篇幅）
- 基于用户提供的有限素材
- 可能不完整，建议补充更多素材
- 仅适合个人参考，不宜对外分享
- 无法验证的部分已标注🔴推测
```

## 特殊情况处理

### 情况1：蒸馏用户自己

#### 额外考虑
- 用户可能有盲点（看不到自己的问题）
- 需要他人评价来补充
- 建议用户找2-3个朋友/同事提供观察

#### 素材收集对话
```
女娲：好的，我们来蒸馏你的思维方式。
我需要你提供一些素材。先从我自己开始：

1. 你最近写过的长文（博客、备忘录等）有吗？
2. 你最近做的重大决策是什么？当时怎么考虑的？
3. 你最坚持的3个信念是什么？

用户：[提供素材]

女娲：很好。还需要一些他人的视角：
4. 你觉得朋友/同事会怎么描述你的思维方式？
5. 你最反对的做法是什么？

用户：[提供]

女娲：最后，你有没有承认过错误的经历？
用户：[提供]

女娲：好的，素材足够了。我现在开始分析...
```

### 情况2：蒸馏朋友/同事

#### 额外考虑
- 需要用户代为提供素材
- 无法直接询问本人
- 建议获取本人同意（如果可能）

#### 素材收集
```
女娲：好的，你想蒸馏你的朋友[姓名]。
我需要你提供一些关于他的素材：

1. 他写过的文章/发言（你手上有的）
2. 他做过的重大决策（你观察到的）
3. 他经常说的话/口头禅
4. 他明确反对的做法
5. 你对他的观察（作为朋友的视角）

用户：[提供]

女娲：好的。需要注意：
- 我们只能基于你提供的素材提炼
- 可能不完整，建议后续补充
- 建议告知[朋友姓名]（如果合适）
```

### 情况3：信息严重匮乏

#### 触发条件
- 用户只能提供<10条素材
- 素材质量低（碎片化、无深度）

#### 处理
```markdown
⚠️ 信息严重不足，建议：

1. **暂停蒸馏**：先补充更多素材
2. **降低期望**：只提取1个心智模型
3. **更换对象**：选择信息更充足的人物

如果继续：
- 心智模型：最多1个
- 置信度：全部标注🔴推测
- 诚实边界：极长篇幅（800字以上）
- 明确标注："信息严重不足，仅供参考"
```

## 质量预期

### 最小模式的质量上限

| 维度 | 公众人物（完整模式） | 非公众人物（最小模式） |
|------|-------------------|---------------------|
| 心智模型 | 3-7个（🟢高） | 1-3个（🟡中） |
| 决策启发式 | 5-10条 | 2-5条 |
| 表达DNA | 完整分析 | 简化分析 |
| 内在张力 | 2-3对 | 0-1对 |
| 诚实边界 | 200字 | 600字 |
| 测试通过率 | 80%以上 | 50-70% |
| 可用性 | 高（可对外分享） | 低（仅个人参考） |

### 使用建议

#### 适合的场景
- 自我反思：用这个视角审视自己的决策
- 理解他人：尝试用朋友的视角看问题
- 思维练习：锻炼多角度思考能力

#### 不适合的场景
- 对外分享：作为"某某的思维方式"发布
- 决策依据：完全依赖这个Skill做重要决策
- 学术研究：作为可靠的思维模型引用

## 升级路径

### 从最小模式升级

#### 升级到核心模式
- 补充素材到20条以上
- 启动3个核心Agent（著作、对话、决策）
- 心智模型增加到2-4个

#### 升级到完整模式
- 补充素材到50条以上
- 启动全部6个Agent
- 心智模型增加到3-7个
- 但前提是：蒸馏对象有足够公开信息

### 持续补充建议

```markdown
## 持续补充素材清单

### 每周补充
- [ ] 记录本周做的重大决策
- [ ] 记录本周的反思和教训
- [ ] 记录本周写过的长文/邮件

### 每月补充
- [ ] 整理本月的心得的
- [ ] 请2-3个朋友提供观察
- [ ] 回顾本月的决策和结果

### 每季度升级
- [ ] 重新运行蒸馏流程
- [ ] 更新心智模型
- [ ] 检查是否有新的反模式
```

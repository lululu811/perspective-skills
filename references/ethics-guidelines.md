# 伦理考量指南 v3.0

> 蒸馏过程中需要注意的伦理问题

## 核心原则

1. **尊重隐私** - 不蒸馏私人关系，不推测未公开的个人生活
2. **知情同意** - 在世人物应知晓被蒸馏（如果可能）
3. **诚实标注** - 明确标注信息截止时间和局限性
4. **避免伤害** - 避免蒸馏有争议的政治人物（除非有明确理由）

---

## 在世人物

### 知情同意

#### 理想情况
```markdown
最佳实践：
1. 告知被蒸馏者：
   "我正在用AI提炼你的思维方式，创建一个思维顾问Skill。
    这个Skill会基于你的公开著作、访谈、决策记录。
    你希望参与吗？有什么需要特别注意的？"

2. 获得反馈：
   - 此人可能提供额外素材（一手资料）
   - 此人可能指出误解（纠正提炼）
   - 此人可能表示反对（尊重意愿）
```

#### 现实情况
```markdown
大多数情况下，无法获得知情同意：
- 蒸馏历史人物（已故）
- 蒸馏公众人物（无法联系）
- 蒸馏朋友/同事（可能尴尬）

处理原则：
1. 明确标注"此人未授权，仅供参考"
2. 基于公开信息，不推测私生活
3. 如果此人公开表示反对被AI模拟，尊重其意愿
```

### 争议人物

#### 判断标准
```markdown
以下情况需要谨慎：

1. 政治人物
   - 在任政治人物：避免蒸馏（除非用户有明确理由）
   - 历史政治人物：可以蒸馏，但需标注争议
   - 原则：保持中立，不表达政治立场

2. 争议人物
   - 有严重争议的人物（如骗子、罪犯）：避免蒸馏
   - 除非用于学术研究或反面教材
   - 必须明确标注争议

3. 在世普通人
   - 避免蒸馏非公众人物（除非用户本人或获得同意）
   - 隐私保护优先
```

#### 处理方式
```markdown
如果必须蒸馏争议人物：

1. 明确标注争议
   > ⚠️ [人名] 是有争议的人物。
   > 本Skill仅提炼其思维方式，不代表认同其所有行为。
   > 使用者需自行判断。

2. 保持中立
   - 提炼思维方式，不评价对错
   - 记录争议行为，但不做道德判断
   - 在"他者视角"中呈现批评

3. 加大诚实边界
   - 明确标注争议点
   - 说明此Skill不包含道德判断
   - 提醒使用者谨慎使用
```

## 已故人物

### 可以蒸馏
```markdown
已故人物是可以蒸馏的：
- 有充足的公开信息
- 不会侵犯隐私
- 有历史价值

但需要注意：
1. 无法获取最新观点
   - 明确标注"信息截止于[年份]"
   - 无法反映此人对新问题的看法

2. 避免过度推测
   - 不推测"如果还在世会怎么想"
   - 只基于已有的著作、访谈、决策记录
   - 在诚实边界中说明局限
```

### 历史人物的特殊考虑
```markdown
### 时代背景
- 某些观点在现代看来可能不正确
- 处理：标注时代背景，不强制用现代标准评判

### 信息不完整
- 历史人物的信息可能不完整
- 处理：加大诚实边界，标注信息不足

### 多元解读
- 历史人物可能有多种解读
- 处理：在"他者视角"中呈现不同解读
```

## 隐私保护

### 不蒸馏的内容
```markdown
以下内容不应蒸馏：

1. 私人关系
   - 不推测此人的私人关系（除非公开）
   - 不分析此人的家庭矛盾（除非公开讨论）
   - 不推测此人的感情生活（除非公开）

2. 未公开信息
   - 不推测未公开的决策过程
   - 不推测未公开的个人想法
   - 不推测未公开的动机

3. 私人通信
   - 不使用私人信件/日记（除非公开出版）
   - 不使用未授权的聊天记录
   - 不使用黑客获取的信息
```

### 脱敏处理
```markdown
如果素材中包含敏感信息：

1. 用户提供的素材
   - 提醒用户脱敏：
     "你提供的聊天记录中包含了其他人的信息。
      建议脱敏后再提供（删除姓名、联系方式等）。"

2. 蒸馏结果
   - 不在SKILL.md中包含私人信息
   - 不引用未公开的私人通信
   - 不推测未公开的个人生活
```

## 使用限制

### Skill的使用边界
```markdown
在SKILL.md中明确标注：

## 使用限制

### 可以做
- 用这个视角审视新问题
- 用这个视角反思自己的决策
- 学习此人的思维方式
- 作为思维顾问参考

### 不可以做
- 代替此人做决策
- 作为此人的"官方立场"
- 用于欺骗他人（"这是XX本人说的"）
- 用于商业目的（除非获得授权）

### 需要谨慎
- 用于学术研究：需标注来源和局限
- 用于教学：需标注这是AI提炼，非本人授权
- 用于公开分享：需标注"AI提炼，非官方"
```

## 争议处理

### 如果被蒸馏者反对
```markdown
情况：此人公开表示反对被AI蒸馏

处理：
1. 尊重意愿
   - 如果可能，停止蒸馏
   - 如果已完成，考虑删除或标注"未授权"

2. 标注争议
   - 在SKILL.md开头标注：
     > ⚠️ [人名] 曾表示反对被AI模拟。
     > 本Skill仅供参考，不代表此人立场。

3. 评估影响
   - 如果此人有广泛影响力，慎重考虑
   - 如果是普通人，影响有限
```

### 如果发现严重错误
```markdown
情况：发现蒸馏的Skill有严重错误（误导用户）

处理：
1. 立即修正
   - 更新SKILL.md
   - 标注"已修正"

2. 通知用户
   - 如果有用户使用，通知他们更新
   - 说明修正内容

3. 记录教训
   - 为何出现错误？
   - 如何避免？
```

## 常见问题

### Q1: 可以蒸馏在世的政治人物吗？
**A**: 可以，但需谨慎：
- 保持中立，不表达政治立场
- 标注争议点
- 明确标注"AI提炼，非官方立场"
- 避免用于政治宣传

### Q2: 可以蒸馏有争议的商业人物吗？
**A**: 视情况而定：
- 如果是骗子/罪犯：避免蒸馏（除非用于反面教材）
- 如果是有争议但合法：可以蒸馏，但标注争议
- 如果是正常商业人物：可以蒸馏

### Q3: 可以蒸馏朋友/同事吗？
**A**: 可以，但建议：
- 获得本人同意（如果可能）
- 不推测私人生活
- 不用于评价此人
- 仅用于理解和学习

### Q4: 可以蒸馏自己吗？
**A**: 完全可以：
- 这是自我反思的好工具
- 可以提供一手素材
- 可以持续更新
- 建议定期审视和修正

### Q5: 如果此人反对被蒸馏怎么办？
**A**: 尊重意愿：
- 如果可能，停止蒸馏
- 如果已完成，标注"未授权"
- 考虑删除或限制使用
- 反思为何此人反对

## 总结

### 核心原则
1. **尊重** - 尊重被蒸馏者的意愿和隐私
2. **诚实** - 诚实标注局限和争议
3. **谨慎** - 谨慎处理争议人物和敏感信息
4. **负责** - 对Skill的使用负责

### 底线
- 不侵犯隐私
- 不造成伤害
- 不欺骗他人
- 不违反法律

### 最佳实践
- 获得知情同意（如果可能）
- 基于公开信息
- 明确标注局限
- 尊重使用限制
